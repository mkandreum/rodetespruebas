## ¿Qué es RodetesPruebas?

RodetesPruebas es el repositorio de pruebas y desarrollo experimental del ecosistema Rodetes de Xyon Platforms. Se utiliza para probar nuevas funcionalidades, integraciones y prototipos antes de llevarlos a producción.

## ℹ️ Uso

Este repositorio es de uso interno para el equipo de desarrollo de Xyon Platforms. No está destinado a producción.

```bash
git clone https://github.com/mkandreum/rodetespruebas.git
cd rodetespruebas
npm install
npm run dev
```
